Aufbau

Der Client kennt die Werkzeuge nicht im Voraus. Er fragt den MCP-Server nach list_tools(), übersetzt die zurückgegebenen Schemas ins OpenAI-Function-Format und reicht sie an das Modell weiter. Ein neues Tool im Server erscheint deshalb ohne eine einzige Codeänderung im Client. 

client.py  ──HTTP──►  LiteLLM-Proxy  ──►  LLM hinter dem Alias gpt-4o-mini
   │                  localhost:4000       31.08.: Azure gpt-5-mini · 14.10.: Gemini
   │
   └──MCP streamable-http──►  server.py   localhost:8010/mcp
                                ├── lookup_products          → SQLite
                                ├── compute_tiered_discount  → Formelmaschine
                                ├── append_audit_event       → audit_log.txt
                                ├── resource audit://log
                                └── resource inventory://schema

Der Modellname gpt-4o-mini ist nur ein Alias im Proxy. Die Protokolle vom 31.08. entstanden mit Azure gpt-5-mini, die Screenshots vom 14.10. mit Gemini — am Client wurde dafür nichts geändert.

Die drei Werkzeuge

01
lookup_productssqlite3

Fragt die Tabelle products ab — Freitext auf SKU und Name, Kategoriefilter, optional nur lieferbare Artikel. Die Query ist parametrisiert: Da die Argumente vom Sprachmodell stammen, wäre String-Verkettung hier eine SQL-Injection-Lücke.

02
compute_tiered_discountFormelmaschine

Marginale Mengenstaffel in fünf Stufen (0 / 5 / 12 / 18 / 25 Prozent), darauf multiplikativ ein Kundenstatus-Nachlass. Gibt die vollständige Aufschlüsselung zurück, nicht nur den Endbetrag — damit das Modell die Rechnung wiedergeben kann, statt sie zu schätzen.

03
append_audit_eventDateiresource

Hängt Zeitstempel | event | details an logs/audit_log.txt an und meldet Zeileninhalt und Zeilennummer zurück. Derselbe Inhalt ist über die MCP-Resource audit://log lesbar: Das Tool schreibt, die Resource liest.

Rechenweg der Formelmaschine

Die Staffel wirkt marginal — jede Stufe gilt nur für die Stück in ihrer eigenen Bandbreite, nicht rückwirkend für die ganze Bestellung. Das Beispiel stammt aus Szenario 2: 250 Näherungssensoren M12 zu 34,20 € für einen Gold-Kunden.
